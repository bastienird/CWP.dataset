# Print a deferred plot

Printing a deferred plot draws it and prints the result, so that a
deferred plot behaves like a plot at the console and in a report.

## Usage

``` r
# S3 method for class 'cwp_plot_spec'
print(x, ...)
```

## Arguments

- x:

  A deferred plot.

- ...:

  Passed to the print method of the plot.

## Value

`x`, invisibly.
