# Render Subfigures from a List of Plots

This function creates a grid of subfigures from a list of plots and
titles.

## Usage

``` r
render_subfigures(plots_list, titles_list, general_title)
```

## Arguments

- plots_list:

  A list of plot objects.

- titles_list:

  A list of character strings for plot titles.

- general_title:

  A character string for the general title of the plots.

## Value

None
