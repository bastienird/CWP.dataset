# Save Plot as Image

This function saves the current plot as an image in a specified folder.

## Usage

``` r
save_image(
  title,
  plott = last_plot(),
  folder = NULL,
  fig.pathinside = fig.path
)
```

## Arguments

- title:

  A character string representing the title of the plot.

- plott:

  The plot object to save.

- folder:

  The folder where the image will be saved.

- fig.pathinside:

  The path for saving the figure.

## Value

None
