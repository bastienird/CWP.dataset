# Read Data from Various File Types

This function reads data based on the provided file path and file type.

## Usage

``` r
read_data(file_path)
```

## Arguments

- file_path:

  A character string indicating the path of the file to read.

## Value

Data read from the specified file, either as a data frame or data table.
