# Compare Georef and Nominal Data

This function takes georef and nominal data as inputs, performs a
comparison, and returns the results.

## Usage

``` r
compare_georef_nominal(georef, nominal, connectionDB)
```

## Arguments

- georef:

  Data frame containing georeferenced data.

- nominal:

  Data frame containing nominal data.

- connectionDB:

  Database connection object.

## Value

A list containing the comparison results.
