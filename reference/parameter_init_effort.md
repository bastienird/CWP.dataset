# Example subset of effort dataset (initial)

A small sample of initial effort data, structured according to CWP
standards.

## Usage

``` r
parameter_init_effort
```

## Format

A tibble with 200 rows and 13 variables:

- source_authority:

  Source of the data (e.g. RFMO)

- gear_type:

  CWP gear type code

- fishing_fleet:

  Fishing fleet country or code

- fishing_mode:

  Fishing mode (e.g., UNK for unknown)

- time_start:

  Start date of the operation

- time_end:

  End date of the operation

- geographic_identifier:

  CWP geographic identifier

- measurement_unit:

  Unit of measurement (e.g., HRSRH)

- measurement_value:

  Measurement value (e.g., hours of effort)

- gridtype:

  Spatial resolution label

- Gear:

  Gear label

- fishing_mode_label:

  Fishing mode label

- fishing_fleet_label:

  Fishing fleet label
